### About Me

I am finishing my **B.S. in Software Engineering (Java Track)** at Western Governors University (WGU), transitioning from a background in complex field diagnostics in residential construction into full-stack and systems-level engineering. 

Years of troubleshooting physical systems taught me how to isolate root causes under real-world constraints—a diagnostic mindset I now apply across the entire stack, from Spring Boot APIs and relational databases down to microcontroller registers.

---

### Engineering Philosophy

Modern software often trades clarity and efficiency for layers of unnecessary abstraction. My goal is to build deterministic, high-efficiency systems where architecture choices are intentional and performance is understood end-to-end:

* **Full-Stack Foundations:** Designing structured, maintainable enterprise applications with Java, Spring Boot, Angular, TypeScript, and MySQL.
* **Systems & Hardware Curiosity:** Studying C/C++, memory management, and microcontroller behavior to understand how high-level logic translates to actual machine execution.
* **Diagnostic Rigor:** Approaching bugs and bottlenecks systematically—tracing symptoms back to their root cause rather than patching around them.

### Featured Projects

#### 1. Washington State Ferries Tracker
`Java 25` · `Spring Boot 4` · `Angular` · `MySQL 8.4` · `Docker Compose`

A full-stack application built to track Washington State Ferries data using a modern enterprise stack.
* **Backend & Persistence:** Java 25 and Spring Boot 4 service backed by MySQL 8.4 for structured relational data storage.
* **Frontend:** Angular single-page interface for viewing and interacting with ferry data.
* **Environment:** Containerized multi-service setup orchestrated with Docker Compose for consistent local development and deployment.

An enterprise Java application developed as part of WGU's Advanced Java coursework, applying object-oriented design, backend business logic, and structured application architecture within a multi-tier Java environment.

#### 3. Interactive World Map Application
`Angular` · `TypeScript` · `REST API` · `Asynchronous Programming`

A dynamic single-page application built for coursework using component-based architecture.

`C` · `C++` · `Microcontrollers` · `Memory Management`

Self-directed systems study focused on understanding execution close to the hardware.
* Exploring direct memory allocation, hardware register manipulation, and sensor communication protocols.
